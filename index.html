Sobre o projeto

Uma iniciativa simples e acessível

O projeto foi criado como uma proposta de presença digital para uma organização do terceiro setor. A interface prioriza clareza, acessibilidade, navegação por teclado e adaptação para diferentes tamanhos de tela.
