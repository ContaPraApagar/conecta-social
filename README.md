# Conecta Social

Projeto acadêmico de front-end para uma organização do terceiro setor.

## Objetivo

Criar uma presença digital simples, responsiva e acessível para apresentar uma ONG,
suas ações e um canal de contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git/GitHub (versionamento)

## Funcionalidades

- Navegação por seções
- Menu responsivo
- Modo claro e escuro
- Formulário de contato demonstrativo
- Navegação por teclado
- Foco visual
- Estrutura HTML semântica
- Layout responsivo

## Acessibilidade

O projeto utiliza elementos semânticos como `header`, `nav`, `main`, `section` e
`footer`. Também foram utilizados `label` em formulários, atributos ARIA quando
necessários, foco visível e suporte à navegação por teclado.

A estrutura foi pensada como referência para WCAG 2.1 Nível AA.

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não são necessárias dependências externas para executar a versão básica.

## Versionamento

O projeto pode ser organizado seguindo GitFlow:

- `main`: versão estável.
- `develop`: desenvolvimento.
- `feature/*`: novas funcionalidades.

Exemplos de Conventional Commits:

- `feat: criar estrutura inicial`
- `feat: adicionar modo escuro`
- `fix: corrigir navegação do menu`
- `fix: melhorar acessibilidade`
- `docs: atualizar README`

A primeira versão estável pode ser identificada como `v1.0.0`.

## Publicação

A pasta contém a versão final do código-fonte. Para publicação, ela pode ser
enviada para um repositório GitHub e conectada a uma plataforma de hospedagem
de sites estáticos.
